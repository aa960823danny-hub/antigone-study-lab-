# Antigone Exam Study Lab

A self-contained, interactive study website for Sophocles' *Antigone*, designed for English multiple-choice exam preparation.

## Features
- 11 story-study sections
- Character relationships
- 99 vocabulary items
- 161 English multiple-choice questions
- Mock exam, review and progress tracking
- Full-text reading experience

## Deploy to GitHub Pages
1. Create a **public** GitHub repository (for example, `antigone-study-lab`).
2. Upload `index.html`, `README.md`, and `.nojekyll` to the repository's **main** branch, at the root.
3. Go to **Settings > Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select **main** and **/(root)**, then click **Save**.
5. Wait for deployment and visit `https://YOUR_USERNAME.github.io/antigone-study-lab/`.

The site is a standalone HTML file and does not need a build process or server. Learning progress is stored locally in the browser, not synced across devices.

## Local preview
Open `index.html` in a modern browser.
